SIGNAL SIEGE ARCADE - CLASSROOM GAME

Open index.html in a modern browser, or upload it to any static host (GitHub Pages, Netlify Drop, university web space) and share the URL as a QR code.

DESIGN GOAL
This version removes the four-tool palette. Students interact directly with threats using four simple gestures: tap, drag, swipe, and timed shield activation.

EVENTS
- Evil twin: tap the impostor AP.
- Rogue AP: drag/tap into IT quarantine.
- Captive portal clone: swipe away or close.
- Deauthentication burst: raise PMF shield.
- Shared password leak: drag/tap to shred and rotate.
- Fake RADIUS certificate: reject it.
- KARMA-style auto-join trap: disable blind auto-join.
- Incident response: reset a compromised account.

AUTOMATIC DEFENSE UPGRADES
3 handled threats: strict server-certificate validation.
6 handled threats: Protected Management Frames.
9 handled threats: WPA3-SAE.

CLASSROOM FORMAT
1. Students scan a QR code and play one 75-second round.
2. Pair discussion: name one threat and the control that stopped it.
3. Play a second round; compare score improvement rather than only highest score.

The game is a self-contained educational simulation. It performs no real wireless scanning, credential capture, or network activity.
